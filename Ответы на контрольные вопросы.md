# ЛР №7. Работа с файлами — ответы на контрольные вопросы

**1. Какая библиотека хранит классы для работы с текстовыми файлами?**
Пространство имён `System.IO`. В нём находятся `StreamReader`, `StreamWriter`, `File`, `Path`, `Directory`.
Кодировки (`Encoding.UTF8` и др.) — в `System.Text`.
В программе: `using System.IO;` в `Services/FileDataService.cs`.

**2. В какой папке хранятся созданные файлы по умолчанию?**
Если указано только имя файла (относительный путь), файл создаётся в рабочей папке программы —
обычно там, где лежит `.exe`: `bin\Debug\net10.0-windows\`.
В программе файлы рейтинга `ratings_<код>.txt` создаются в `bin\Debug\net10.0-windows\Data\`.

**3. Как получить путь к базовой директории проекта?**
`AppDomain.CurrentDomain.BaseDirectory` — папка, из которой запущено приложение (где `.exe`).
Полный путь к файлу собирается через `Path.Combine`, он сам подставляет нужный разделитель (`\` или `/`):
```csharp
string path = Path.Combine(AppDomain.CurrentDomain.BaseDirectory, "Data", "teachers.txt");
```

**4. Для чего нужен класс File? Какие у него имеются особенности?**
`System.IO.File` — класс для операций с файлами целиком: проверка существования (`File.Exists`), создание,
чтение и запись (`ReadAllLines`, `WriteAllText`), копирование, перемещение, удаление, получение информации.
Особенность: класс **статический** — нельзя создать объект (`new File()` — ошибка компиляции),
методы вызываются через имя класса (`File.Exists(path)`), и он не хранит состояние.
В программе `File.Exists` проверяет, есть ли `teachers.txt`, список студентов и сохранённый рейтинг.

**5. Для чего необходимо указать метод Close() после записи/чтения данных?**
Поток — это занятый ресурс операционной системы. Пока поток не закрыт:
- файл остаётся заблокированным, другие программы (и сама программа) не могут его открыть;
- данные `StreamWriter` могут остаться в буфере и не попасть в файл;
- при многократных операциях накапливается утечка ресурсов.
`Close()` сбрасывает буфер в файл и освобождает ресурсы.

**6. Какая существует альтернатива ручному закрытию файла?**
Оператор `using`. Объект в его скобках должен реализовывать `IDisposable`; при выходе из блока
(в том числе при исключении) автоматически вызывается `Dispose()`, который закрывает поток:
```csharp
using (StreamWriter writer = new StreamWriter(path, false, Encoding.UTF8))
{
    writer.WriteLine("...");
}   // здесь поток закрыт автоматически
```
В программе все чтения и записи (`LoadTeachers`, `LoadDisciplines`, `LoadRatings`, `SaveRatings`)
сделаны через `using`.
